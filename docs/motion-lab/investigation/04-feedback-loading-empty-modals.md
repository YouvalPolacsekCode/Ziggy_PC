# Feedback, loading, empty states, modals/sheets/menus, errors, anomalies, suggestions (origin/main e44e163)

## 1. Toast (`ui/Toast.jsx` + `uiStore.js:45-88`)

Fixed, `bottom: calc(var(--nav-h) + max(var(--safe-bottom), 8px) + 12px)`, centred, `maxWidth 400`, `zIndex 60` (same anchor on desktop). Enter `{opacity 0, y 8, scale .98}` → 240ms `EASE_ENTER`; **exit `{0, -4, .98}` at the same 240ms — not faster than enter**. Flex column gap 8, **newest appended last (below)**; no max length; **no `layout`** → siblings jump on removal. `AnimatePresence` children are plain keyed `<div>`s wrapping the `motion.div` (fragile). Duration `error 7000 / else 3000`. Dedupe identical `type:message` within 4000ms (dropped silently). Variants success/error/warning/info = 8px dot + `color-mix(8%, --surface)`. Usage: **190 `'error'`, 119 `'success'`, 1 `'info'`, 0 `'warning'`**. X dismiss; `detail` disclosure with no height animation. **No undo** anywhere (the only Undo is in `BundlePreviewCard`). Dead: `uiStore.toastError` (the `describeError` helper, never called). Wall has a second toast (`.zw-toast`) with **no animation at all**.

## 3. Loading

`DataState` API `{loading, error, empty, onRetry, renderSkeleton/Empty/Error, emptyMessage}` — priority error > loading > empty > children; defaults are centred text, no spinner, no animation. **Imported by zero components.**

Patterns: `.z-spin` (~30 sites) · `.z-pulse` (health dot in recovery, IR learning) · Tailwind `animate-pulse` (HomeMap, IR live dot) · **static grey skeleton blocks, deliberately no pulse** (Anomalies 2×/3×100px, Suggestions 3×120, Tasks 4×56, Actions 3×82, Rooms 4 tiles, Devices 6×60, DeviceDetail 34+3×96 "no pulse loop", Cameras, QuickAsks, VirtualDevices, FleetOps `.zg-skel`) · plain "Loading…" text (Hub, People, EntitySelect) · `data-pending` breathe · one framer looping ring (`PairingWizard.jsx:737-741`, `{scale [1,1.18,1], opacity [.5,.1,.5]}` 2s) · button text swaps ("Adding…", "Saving…", "…"). `Button.jsx` has **no `loading` prop**. Stale-while-revalidate dominant (skeleton only when `loading && list.length === 0`). **Data arrival = hard pop-in everywhere**; the only arrival motion is `data-motion-stagger` on a few grids and the page-enter rise.

## 5. Success / error feedback after an action

Uniform: local `pending` → `data-pending` breathe and/or `opacity .7` → toast on completion. Toggle a light (dashboard): **no toast**, WS state flips `data-on` → 220/160ms + ignition; error toast. Scrub: one command on release, value held 600ms. Long-press room: toast `"{Room} · On|Off"` + forced refetch. Run routine/automation: `Loader2 z-spin` + toast `Triggered: {name}` / `Triggered`; on Actions the card has **no busy state**; the real outcome is a WS toast `'{label} — {n} step(s) completed'` seconds later. Save task: toast + label swap. Toggle task done: no toast; checkbox ring 200ms. Anomaly action / snooze: hard-coded EN toasts + full refetch. Suggestion accept/reject/snooze: toasts + `suggestionStore.fetch()` replaces the array. Pairing: in-wizard steps; `CountdownRing` + looping halo. Anomaly rule toggle: **optimistic with no rollback**. Bundle apply: in-card `SUCCESS` with **Undo**, `UNDONE`, `RESULTS` pass/fail. Network errors: `ZiggyApiError` with i18n code map; call sites read `e.message`. Subscription gate: fixed top strip z 9000, cut in/out. Wall commands: `useOptimistic` with real rollback.

## 6. Connection / network status

`useNetworkStatus`: `wsConnected` → online; `!online && !wsConnected` → offline; else connecting. `ConnectionStatus.jsx`: `DEBOUNCE_MS 2000`; offline `--err` "You're offline" / connecting `--warn` "Reconnecting to Ziggy…"; `position: sticky`; enter `ziggy-banner-in` (`translateY(-100%)` + opacity, `--dur-enter`); **exit: `return null` → the sticky in-flow banner is removed in one frame and the page snaps up. No "Back online" despite `status.backOnline` existing in i18n.** `SystemHealthBanner.jsx`: seven states → severity; **no enter, no exit, no transition**; dot `.z-pulse` only during recovery; severity escalation cuts. BottomNav pins itself when `connected === false`. `ErrorBoundary` swaps in/out as cuts.

## 7. Anomalies & suggestions

Anomaly card: 3px severity edge, 36px tinted icon, 15/600 message, subtitle, 12px mono meta, Snooze menu + Action / status chip. `motion.div layout`, `{opacity 0, y 6}` → exit `{0, scale .97}` `T_ENTER`; `AnimatePresence popLayout`. Snooze: menu closes instantly, then API → toast → `loadActive()` **full refetch** — the card leaves one round-trip later. Action: same via `refreshAfterChange()`; label `'…'` while busy. Re-sorted by severity on every refetch. Two sections (needsAttention / earlierToday) = two AnimatePresence trees → severity change is exit + enter. Rules tab: optimistic, no rollback; exemption chips removed with no exit.

Suggestion card (`Suggestions.jsx` LEGACY; canonical `SuggestedTab.jsx`): eyebrow, `ConfidenceMeter` (82% + five 4px dots, static), body, WHEN/DO summary, why-disclosure (framer `height 0→auto` — animates a layout property, contrary to the layer's rule), evidence, `[Yes, create] [Later] [✕]`. `layout` + `popLayout`; after action `suggestionStore.accept/reject/snooze` awaits the API then `fetch()` replaces the whole array → the card leaves after **two round-trips**; per-button `acting` (`opacity .6` + "…") is the only interim feedback; items teleport between Pending and History tabs. Stat strip counts swap.

## 9. What cuts

Banners reflow instantly (ConnectionStatus exit, SystemHealthBanner both ways, SubscriptionGate, Hub PairBanner, People error/skeleton/empty). Every skeleton pops to content. Menus with no exit or no motion (Rooms overflows, EntitySelect, native Select, More exit, wall modals, hub picker, WallToast). Counts and tabs swap (Suggestions stat strip, Anomalies counts, Tasks headers; `boxShadow` toggled without transition on segmented pills). Toast detail body no height animation; no `layout` on toasts. Input focus `outline` not animatable. Two-tap confirm instant. Blasters inline confirm no animation. Exemption chips no exit. `Button` no loading state. Modal same duration in/out. Anomaly rule toggle no rollback. Cross-container teleports (tasks, anomalies, suggestions). Specified-but-unwired: `data-motion-live`, `DataState`, `toastError`; orphan i18n `status.backOnline`, `status.degradedSomeFeatures`, `devices.emptyHint`, `tasks.deleteConfirm`, `alerts.empty`, `health.action.dismiss`; hard-coded English in Anomalies and Devices empties.
